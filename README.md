# For Kavya 💗

A heartfelt, interactive apology website — handcrafted with HTML, CSS, JavaScript, and a genuinely sorry heart.

## How to Run

1. **Open `index.html`** in any modern web browser (Chrome, Firefox, Edge, Safari).
   - Double-click the file, or
   - Right-click → Open With → your browser, or
   - Drag the file into an open browser window.

2. That's it. No server, no build tools, no dependencies.

## What's Inside

| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | All styles, animations, and responsive design |
| `script.js` | Interactions, scroll reveals, mini-game, and animations |
| `README.md` | You're reading it |

## Features

- 💌 **Cinematic envelope opening** — tap to reveal the main experience
- 📝 **Heartfelt apology letter** — with line-by-line reveal animation
- 🧠 **Self-reflection cards** — three honest commitments with hover effects
- 🎮 **Friendship repair mini-game** — deploy chocolates, hugs, and puppy eyes
- 💗 **Heart burst finale** — a beautiful particle burst to close things out
- 📱 **Fully responsive** — works on phones, tablets, and desktops
- ♿ **Accessible** — keyboard navigable, screen-reader friendly, respects reduced-motion

## Technical Notes

- Uses only vanilla HTML5, CSS3, and JavaScript (ES6+).
- Google Fonts (Playfair Display, Inter, Caveat) are loaded if available; system fonts are used as fallbacks.
- No external dependencies, npm packages, frameworks, or build tools.
- No data collection, analytics, cookies, or tracking of any kind.
- No personal photographs or private information.
